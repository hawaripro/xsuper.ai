- `AudioGenerationService`: shared pipeline accepts kinovi providers; music submit omits `duration` when the model has none and forwards `settings` flags.
- `AudioController`: **the emergency pause now covers both audio paths** (it previously covered neither); capability submissions (`operation`) route via the coordinator; while activation is restricted a non-coordinator member keeps the verified fal path and **never sees kinovi audio** (no dead controls). `MediaModelConfig::allowedFor` dropped its stale audio→fal-only guard (the curated kinovi whitelist already constrains).
- Capability contract: music declares `duration` only when the model has it, `tempo` guidance, and Suno's `instrumental`/`custom`; `publicModel` exposes the flags.

Frontend (`AudioGenerator.jsx`)

- Suno toggles: "Gunakan lirik sendiri" (prompt becomes lyrics; label/placeholder switch) and "Instrumental tanpa vokal". Duration slider hides for models without one; validation no longer demands a duration the model lacks.
