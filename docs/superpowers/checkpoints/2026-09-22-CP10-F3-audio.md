## Delivered

Backend
- Migration `2026_09_22_100006_add_capability_to_audio_jobs`: the same coordinator columns image/video carry (`capability_revision_id`, `routing_identity`, `price_tokens`, `dedup_key`, `payload_fingerprint`, `reference_asset_ids`) plus `settings` for declared provider flags the fixed `voice/speed/duration/tempo` columns cannot express. All nullable; legacy rows untouched.
- `MediaGenerationCoordinator::startAudio` — mirrors `startImage`: resolve → validate → price/hash 409 guards → dedup/idempotency → reserve → persist (revision + routing + price) → dispatch. Tempo remains prompt-level guidance ("Tempo guidance: approximately N BPM.") exactly like the legacy pipeline, enforced against the model's character limit.
- `KinoviProtocol`: curated **Suno prompt-only audio** — `suno-music` (16 credits/request upstream; `instrumental` + `custom` lyrics flags; Kinovi returns two tracks) and `suno-sounds` (4 credits; plain prompt). `suno-remix`/`suno-sample` stay excluded: they need uploaded input audio. `audioTask()` builds the createTask body.
- `AiProviderTransport`: `submitAudio`/`audioStatus` gained kinovi branches (`createTask`/`recordInfo`), reusing `kinoviTaskState`.
- `AudioGenerationService`: shared pipeline accepts kinovi providers; music submit omits `duration` when the model has none and forwards `settings` flags.
- `AudioController`: **the emergency pause now covers both audio paths** (it previously covered neither); capability submissions (`operation`) route via the coordinator; while activation is restricted a non-coordinator member keeps the verified fal path and **never sees kinovi audio** (no dead controls). `MediaModelConfig::allowedFor` dropped its stale audio→fal-only guard (the curated kinovi whitelist already constrains).
- Capability contract: music declares `duration` only when the model has it, `tempo` guidance, and Suno's `instrumental`/`custom`; `publicModel` exposes the flags.

Frontend (`AudioGenerator.jsx`)
- Submits the capability payload (`operation: text_to_speech|music`); params travel only when the model declares them, so Suno sends nothing it does not support.
- Suno toggles: "Gunakan lirik sendiri" (prompt becomes lyrics; label/placeholder switch) and "Instrumental tanpa vokal". Duration slider hides for models without one; validation no longer demands a duration the model lacks.
