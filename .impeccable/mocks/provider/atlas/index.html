Yang perlu diketahui.

Apakah prototype ini mengirim request ke API?

Tidak. Semua respons, key, dan catatan request adalah contoh lokal. Tombol salin hanya menyalin teks ke clipboard bila browser mengizinkan.

Apakah UltrAI membuat model-model ini?

UltrAI adalah identitas platform dan pengalaman produk. Claude dikembangkan oleh Anthropic, GPT oleh OpenAI, dan Gemini oleh Google.

Di mana saya menyimpan API key?

Simpan sebagai secret atau environment variable di server. Jangan masukkan key asli ke HTML, JavaScript frontend, repositori publik, atau prototype ini.
