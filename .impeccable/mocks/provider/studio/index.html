Mulai dari sisi server.

Simpan API key dalam environment variable di server Anda, bukan di kode frontend, repository publik, atau tangkapan layar. Contoh memakai ULTRAI_API_KEY; isi dengan kredensial valid hanya di lingkungan Anda sendiri.

Endpoint dan autentikasi

Base URL yang ditunjukkan aplikasi adalah https://api.ultrai.id/v1. Contoh chat menggunakan POST /chat/completions dengan header Authorization: Bearer <API_KEY> dan Content-Type: application/json.

Di prototype ini tidak ada request yang benar-benar dikirim.

Memilih model

Parameter model pada contoh menggunakan auto, sesuai contoh integrasi aplikasi saat ini. Gunakan ID model yang tersedia untuk akun Anda saat integrasi sungguhan.

GPT-4o dibuat oleh OpenAI, Claude Sonnet oleh Anthropic, dan Gemini Pro oleh Google. UltrAI menyediakan pengalaman platform, bukan mengklaim kepemilikan model-model tersebut.

Membaca respons dan error

Contoh respons chat menempatkan teks di choices[0].message.content. Periksa HTTP status sebelum membaca hasil.

Contoh 401 menunjukkan autentikasi yang tidak valid. Jangan mengatasi error autentikasi dengan menanam kredensial ke frontend. Periksa key dan akses di sisi server.

Apa yang nyata dalam prototype ini?

Anda dapat berpindah halaman, menyusun percakapan contoh, menyalin kode, memfilter tabel, serta membuat atau mencabut key dummy. Semua data lokal dan sintetis. Tidak ada akun, tagihan, model, atau API nyata yang dipanggil.
